☕ Nuestros Cafés

📌 Descripción

Nuestros Cafés es una aplicación web desarrollada con React que permite explorar diferentes tipos de cafés mediante una galería interactiva. Cada café cuenta con un título, una imagen y una descripción.

La aplicación permite avanzar y retroceder entre los cafés utilizando botones de navegación. Además, las imágenes cuentan con una transición suave para mejorar la experiencia visual.

✨ Funcionalidades

Visualizar diferentes tipos de cafés.

Mostrar el título, la imagen y la descripción de cada café.

Navegar entre los cafés con los botones Anterior y Siguiente.

Indicar la página actual y la cantidad total de cafés.

Aplicar una transición animada al cambiar de imagen.

Adaptar el diseño a diferentes tamaños de pantalla.

🛠️ Tecnologías utilizadas

React: para construir la interfaz de usuario.

JavaScript: para la lógica y la navegación entre los cafés.

HTML: para la estructura de la aplicación.

CSS: para los estilos, el diseño responsive y las animaciones.

Vite: para crear y ejecutar el proyecto de React.
